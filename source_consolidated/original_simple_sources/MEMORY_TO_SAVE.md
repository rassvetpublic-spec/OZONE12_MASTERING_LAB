# Что прописать в постоянную память проекта

Для проекта `OZONE12_MASTERING_LAB` при повторяющихся анализах Ozone 12 использовать быстрый набор инструментов `OZONE12_STAGE_TOOLKIT` / `ozone12_stage_toolkit`: `oz12_analyze_stage.py` для WAV-метрик и A/B, `oz12_xml_audit.py` для ElementChain/XML diff, `oz12_make_stage_pack.py` для подготовки новой стадии. Перед каждым новым этапом проверять актуальные WAV/XML в `/mnt/data`, не работать только по памяти. Активную цепь Ozone 12 Advanced определять только через `Global/ExtraBytes ElementID="ElementChain"`, не через `Enabled=1`. Для Dirty Vibe текущая пересборка идёт от `01C_bass_stress_FULL_V7` через safe-order `EQ → Impact → Clarity → Stabilizer → Stereo Imager → Dynamic EQ → Maximizer`. Maximizer управлять через `Gain`, а не только `Target Loudness [dB]`. Stabilizer настраивать через `Transient/Sustain` параметры и отдельно учитывать `TameTransients=On`. Для каждого этапа делать CSV/Markdown отчёты: metrics, sample_identity, band_deltas, mid_side_deltas, decision. Финал не утверждать без слуховой проверки и codec audit.
