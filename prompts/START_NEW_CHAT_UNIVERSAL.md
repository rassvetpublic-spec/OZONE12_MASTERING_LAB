Старые ZIP/MD/CSV и track files использовать только как labeled references. При конфликте приоритет у v1.3.

Начни новый прогон OZONE12_MASTERING_LAB.
Сначала составь source_registry.md: source WAV, optional MP3 reference, creative task/style, current base/winner XML, previous accepted renders/reports.

Не работай по памяти. Укажи PluginVer/Build и декодируй ElementChain. Стандартная цепь: Equalizer → Impact → Clarity → Stabilizer → Stereo Imager → Dynamic EQ → Maximizer. Master Rebalance — только optional pre-stage.

Для каждого stage напиши active module, base, provenance, changed only, unchanged modules, probe/candidate, render names и checks. Если эффект почти не слышен — one-module boundary probe. Если пользователь выбрал GUI XML — он новая база.

Без отдельного теста не включать Stereoize, Soft Clip, Low Level Boost, Normalize или внешний limiter. Mono loss важного инструмента и слышимая потеря drum attack — reject/stop.
