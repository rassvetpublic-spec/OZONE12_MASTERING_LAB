# Source Consolidated

Здесь сохранены полные простые источники и старые explainers, чтобы их можно было убрать из активных Sources проекта.

Важно: файлы внутри `source_consolidated/` — archival/reference. Если они конфликтуют с `docs/`, приоритет у `docs/` Universal Core v1.1.

Трековые full XML examples из старых ZIP не включены, чтобы не переносить конкретику одного трека в универсальное ядро.
